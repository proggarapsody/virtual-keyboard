# Product discovery

## Settled in the supplied chat history

- Rewrite virtual-keyboard using Svelte.
- An expressive virtual keyboard studio: users customize visuals, sounds, and reactions while typing.
- First audience: people who enjoy personalizing their typing experience.
- Work in `keyboard-artist` with project-local agent skills.
- Include official Svelte skills, Impeccable, Anthropic frontend-design, and the selected Addy Osmani skills.
- Commit and push the setup; continue grilling afterward.

## Verified legacy behavior

`origin/dev` contains a vanilla JavaScript, Webpack, and Sass app. It has desktop/mobile layouts, English/Russian typing, physical key highlighting, virtual key clicks, and Orange/Pink/Blue themes. Only language and theme persist locally. There is no audio implementation. `main` initially contained only a README.

## Open

The first complete user journey, customization depth, sound authoring, persistence and sharing, device support, visual direction, keyboard layouts, and delivery criteria remain to be decided through grilling. These are not implementation commitments.

## Current implementation boundary

Only the development foundation is installed. The Vite starter is temporary. Do not implement the product until the interview reaches shared understanding and the user confirms it.
